# VEYRO Website — Cloudflare Pages

This is the first static HTML/CSS/JS recreation of the VEYRO Shopify homepage.

## Files
- index.html — page structure and text
- style.css — design and responsive layout
- script.js — small interactions
- images/ — replace placeholder assets here

## Cloudflare Pages
Connect this repository to Cloudflare Pages.
- Production branch: main
- Framework preset: None
- Build command: exit 0
- Build output directory: /

Before publishing, replace the placeholder image blocks with VEYRO-approved image assets and change the contact email in index.html.
